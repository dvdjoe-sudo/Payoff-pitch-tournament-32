# Tournament leaderboards

This file is a pointer. The tournament keeps one generated leaderboard, [LEADERS.md](LEADERS.md), one team file, [TEAM_STATS.md](TEAM_STATS.md), and one box score per game in [box_scores/](box_scores/).

`scripts/build_leaders.py` writes all three, plus [AWARDS.md](AWARDS.md) and [RECORDS.md](RECORDS.md). Do not keep a second board.
